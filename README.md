# Mi Portafolio Personal en React 💼

Este es mi sitio web personal desarrollado con **React**, donde presento mi perfil profesional, mis habilidades técnicas y una selección de mis proyectos reales.

## 🚀 Características

- Sección de presentación personal
- Información sobre mi experiencia y enfoque de trabajo
- Listado de proyectos con descripción e imagen
- Diseño responsive
- Animaciones suaves en UI
- Código organizado en componentes reutilizables

## 🛠️ Tecnologías utilizadas

- **React**
- **JavaScript**
- **CSS**
- **Google Fonts**
- **Git & GitHub**
